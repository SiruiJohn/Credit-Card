# 评估协议（第1阶段定稿）

## 1. 任务定义
- 任务类型：二分类（`0=normal`, `1=fraud`）
- 目标：在高召回下控制误报，支持风控预警

## 2. 数据划分与验证
- 主数据集：`Credit Card Fraud Detection/creditcard.csv`
- 外部验证集：`Credit Card Fraud Detection_2023/creditcard_2023.csv`
- 主数据验证：`5-fold` 交叉验证（分层抽样）
- 外部测试：在主数据调参后，固定阈值迁移到 2023 数据评估泛化

## 3. 指标体系
- 核心指标：`Recall`、`F1`、`PR-AUC`
- 辅助指标：`Precision`、`ROC-AUC`、`Accuracy`
- 结论优先级：PR 曲线相关指标 > ROC-AUC > Accuracy

## 4. 阈值策略
- 默认阈值：`0.5`
- 搜索区间：`0.05 ~ 0.95`（步长 `0.05`）
- 选择原则：
  - 优先满足 `Recall >= 0.85`
  - 在满足召回下，选择 F1 或 Precision 更高的阈值

## 5. 对比口径
- 所有模型使用相同数据切分与指标计算逻辑
- 同时报告：
  - 平均性能（交叉验证均值）
  - 方差稳定性（交叉验证标准差）
  - 训练耗时和推理耗时

## 6. 风险控制
- 严禁数据泄漏（标准化仅用训练折统计量）
- `Accuracy` 不单独作为优劣判断依据
- 外部验证结论需说明分布差异影响
