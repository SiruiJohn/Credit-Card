# AI3013 机器学习课程项目规划

## 1. 项目基本信息
- 项目题目：基于从零实现机器学习模型的信用卡欺诈检测与跨数据集泛化分析
- 项目类型：监督学习（二分类）
- 应用场景：金融风控中的欺诈交易识别与预警
- 目标：在保证较高召回率的前提下，尽量降低误报率，提升模型在不同数据分布下的稳定性

## 2. 选题与数据集选择
### 2.1 选题动机
- 信用卡欺诈检测是典型的高价值真实问题，具有明显业务意义与工程挑战
- 数据具有极端类别不平衡特征，适合开展模型鲁棒性与评估指标合理性分析

### 2.2 数据集概况（项目现有）
- 主数据集：`Credit Card Fraud Detection/creditcard.csv`
  - 样本量：284,807
  - 特征数：31（含标签 `Class`）
  - 标签分布：正常 284,315，欺诈 492，欺诈占比约 0.17%
- 外部验证集：`Credit Card Fraud Detection_2023/creditcard_2023.csv`
  - 样本量：568,630
  - 特征数：31（含标签 `Class`）
  - 标签分布：1:1 平衡
- 备选数据：`Fraud Detection Credit Card/creditcard.csv`
  - 与主数据集字段同构，建议作为备用，不单独作为核心实验数据源

### 2.3 最终选择
- 主实验数据：`creditcard.csv`（真实不平衡分布）
- 泛化验证数据：`creditcard_2023.csv`（分布变化验证）

## 3. 问题定义与技术路线
## 3.1 任务定义
- 输入：交易特征（`V1-V28`、`Time/Amount` 等）
- 输出：交易类别（欺诈/非欺诈）
- 任务性质：二分类概率预测 + 阈值决策

### 3.2 模型设计（满足“至少两个模型、从零实现”要求）
- 模型 1：Logistic Regression（从零实现）
  - 核心内容：Sigmoid、交叉熵损失、梯度下降优化、类别权重/阈值调优
- 模型 2：Gaussian Naive Bayes（从零实现）
  - 核心内容：条件独立假设、类条件高斯分布参数估计、后验概率计算
- 可选增强模型（提升工作量与对比深度）：kNN（从零实现）

### 3.3 数据预处理
- 标签字段统一（`Class` / `class`）
- 缺失值与异常值检查
- 数值特征标准化（重点处理 `Amount`）
- 训练集内部处理类别不平衡（类权重或采样策略）
- 严格划分训练/验证/测试，避免数据泄漏

## 4. 理论与实验设计
### 4.1 理论部分
- 给出 Logistic Regression 的损失函数与梯度推导
- 说明 Naive Bayes 的概率建模假设与参数估计方法
- 比较两种模型的假设条件、优势、局限与适用场景
- 分析时间复杂度与空间复杂度（训练和推理阶段）

### 4.2 评估指标
- 主要指标：Recall、Precision、F1、PR-AUC
- 辅助指标：ROC-AUC、Accuracy
- 说明：在极不平衡数据上重点关注 PR 相关指标，不以 Accuracy 作为主要结论依据

### 4.3 验证策略
- 在主数据集上进行 K 折交叉验证（如 5-fold）
- 进行阈值敏感性分析（不同阈值下 Precision/Recall 变化）
- 在 2023 数据集上做外部测试，评估跨分布泛化能力

### 4.4 可视化与结果呈现
- 类别分布图
- PR/ROC 曲线
- 混淆矩阵
- 阈值-指标曲线（Recall/Precision/F1）
- 模型性能与计算开销对比表（训练时间、内存占用）

## 8. 风险与应对
- 风险 1：类别极不平衡导致模型“高准确率低识别率”
  - 应对：以 Recall/F1/PR-AUC 为主，加入类权重与阈值优化
- 风险 2：从零实现存在数值稳定性问题
  - 应对：加入数值裁剪、日志监控、单元测试和小样本对拍
- 风险 3：报告后期时间紧
  - 应对：按周沉淀图表与文字，阶段性合并文档

## 9. 预期成果

- 提供跨数据分布的泛化评估，为实际风控部署提供参考
